# 10-Templates-and-Examples

Módulo de funciones propio, plantillas de cabecera y ejemplos de referencia (WinForms, XML).

## Scripts de esta categoría

| Script | Qué hace | Tecnología principal |
|---|---|---|
| `AAGFunctions.ps1` | **Módulo de funciones propio** que sirve de base a buena parte de los scripts de SCCM del repositorio. Es la pieza que se importa con `Import-Module C:\01.Scripts\AAGFunc | SCCM / ConfigMgr |
| `Templates-Comments.ps1` | **Plantilla de cabecera** con la ayuda basada en comentarios (comment-based help) de PowerShell, para arrancar nuevos scripts de forma consistente. |  |
| `Windows-Form.ps1` | **Ejemplo de formulario WinForms** en PowerShell, usando como caso el aviso de deshabilitación de Internet Explorer. | WinForms (GUI) |
| `Windows-Form_autogenerate.ps1` | Ejemplo de **generación dinámica de objetos a partir de un XML** (`domains.xml`), como paso previo a poblar una interfaz. | Parsing XML |
| `arraylists.ps1` | Ejemplo de uso de **ArrayLists** para hacer un **cruce a tres bandas** entre grupos de Azure AD y grupos on-prem. | `System.Collections.ArrayList` |
