# Dax40.py

Script **personal** de análisis técnico bursátil: descarga la cotización del **DAX 40** y calcula indicadores como el RSI.

## Cómo funciona
Con `yfinance` descarga la serie de precios y, usando `pandas`/`numpy`, calcula el RSI (medias móviles de ganancias/pérdidas) y otros indicadores, representándolos con `matplotlib`.

## Tecnología
`yfinance` · `pandas` · `numpy` · `matplotlib`.

## Notas
No es código corporativo; es un ejercicio personal de análisis de mercados. Se conserva por integridad del backup.
