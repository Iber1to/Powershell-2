# Delete-ChromeOldVersions.ps1

Variante de la comprobación de Chrome orientada a **limpiar versiones antiguas** (el umbral por defecto está a 0 para forzar la evaluación de todo).

## Cómo funciona
Comparte la lógica de `ChromeUninstallMinimunVersion.ps1` pero enfocada a localizar y retirar instalaciones de Chrome obsoletas.

## Tecnología
Registro / detección de versión.

## Notas
Pensado junto a `chrome_Uninstall.ps1`.
