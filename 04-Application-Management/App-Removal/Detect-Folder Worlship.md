# Detect-Folder Worlship.ps1

Script de **detección** que comprueba la presencia de una carpeta/aplicación concreta (UPS WorldShip, según el nombre) en el equipo.

## Cómo funciona
Con `Set-StrictMode` y manejo de errores estricto, comprueba si existe la ruta/carpeta objetivo y devuelve el código de salida correspondiente para una remediación de Intune.

## Tecnología
Sistema de ficheros · modelo de detección de Intune.

## Notas
El nombre del fichero conserva la errata original ("Worlship").
