# SCCMuninstall_client_APAC.ps1

Variante para **APAC** del script de desinstalación del cliente de ConfigMgr. Misma limpieza base (ccmsetup /uninstall, `smscfg.ini`, certificados SMS y namespaces WMI) con los ajustes propios del dominio APAC.

## Notas
Ver `SCCMuninstall_client.ps1` para el detalle del proceso de limpieza. Existen también las variantes EMEA y LATAM1.
