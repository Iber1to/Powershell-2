# BoundaryCheck_2.ps1

Variante de `BoundaryCheck.ps1`. Mismo objetivo —cruzar la IP reportada por cada equipo de una colección contra las boundaries de tipo *IP range* y separar los que no encajan— con pequeñas diferencias respecto a la versión base (ajustes de filtrado/salida).

## Notas
Se conserva junto a `BoundaryCheck.ps1` y `BoundaryCheck_3.ps1` por ser una de las iteraciones del mismo script; consulta la documentación de la versión base para el detalle del algoritmo de rangos IP.
