# testSignScripts.ps1

Prueba de **firma de scripts** y subida a SharePoint.

## Cómo funciona
Recorre los scripts de una carpeta (`C:\Sign`) para firmarlos y carga los ensamblados del cliente de SharePoint (`Microsoft.SharePoint.Client.dll`) para subir el resultado a SharePoint Online.

## Tecnología
Firma de código (Authenticode) · SharePoint Online CSOM.

## Notas
Banco de pruebas del flujo de firmar scripts y publicarlos.
